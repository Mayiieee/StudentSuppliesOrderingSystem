# Student Supplies Ordering System

A beginner-friendly web project for browsing student supplies, adding items to a cart, completing a mock payment, and viewing an order receipt.

## Features

- Browse available student supplies
- Add selected items to a shopping cart
- Review items before checkout
- Enter payment information through a payment page
- Display an order receipt after checkout
- Simple navigation between pages
- Responsive styling for a clean user interface

> This project is a front-end demonstration. It does not process real payments unless a payment service and back-end are added.

## Technologies Used

- **HTML5** — page structure and content
- **CSS3** — layout and visual styling
- **JavaScript** — cart behavior and page interactions
- **Images** — product pictures and interface graphics
